# Score Reading Trainer

ピアノの譜読みを鍛えるための Web アプリケーション。

## 機能一覧

### 五線譜表示

- ト音記号 / ヘ音記号の切替
- 10 種の調号に対応 (C, G, D, A, E, B, F, Bb, Eb, Ab)
- 臨時記号の ON/OFF (シャープ、フラット、ナチュラル、ダブルシャープ、ダブルフラット)
- 加線が多くなる音域には 8va / 8vb を自動表示

### 音域設定

- 最低音・最高音を自由に設定 (A0 〜 C8)
- 設定範囲内のスケール音 (臨時記号 OFF 時) またはすべての半音 (ON 時) から出題

### 鍵盤

- 設定音域に連動したピアノ鍵盤を画面下部に表示
- **全体表示モード:** 画面幅に収まるよう鍵盤サイズを自動調整
- **スクロールモード:** 固定幅で横スクロール
- 白鍵に音名ラベル表示 (ON/OFF 可)

### 音声

- 4 種の音色 (Triangle, Sawtooth, Square, Sine)
- 音量スライダー (-40dB 〜 0dB)
- MIDI キーボードでは押している間鳴り続ける (和音対応)

### ヒント

| ヒント | 説明 |
|--------|------|
| 押した音を譜面に表示 | 入力した音を青い音符で五線譜に重ねて表示 |
| 正解キーを表示 | 正解の鍵盤を黄色でハイライト |
| 音名表示 | 白鍵に C4, D4 などのラベルを表示 |
| キーボードレイアウト表示 | 鍵盤上に対応する PC キー名 (A, W, S...) を表示 |

### PC キーボード

白鍵・黒鍵を以下のキーに割り当て。オクターブは問わず、音名のみで判定する。

```
 W  E     T  Y  U
A  S  D  F  G  H  J
```

### MIDI キーボード

USB 接続の MIDI キーボードに対応 (Web MIDI API)。オクターブを含む正確な判定を行う。
接続状態は画面下部の MIDI ステータスに表示される。

### マウス / タッチ

画面上のピアノ鍵盤を直接クリックまたはタップ。オクターブを含む正確な判定。
